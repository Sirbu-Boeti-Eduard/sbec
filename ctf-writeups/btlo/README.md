# Blue Team Labs Online

Writeups for Blue Team Labs Online investigations and challenges.

## Writeups

- [BTLO: SOC Alpha 1](soc-alpha-1.md) — An alert-driven SOC investigation using Elastic and Sysmon to trace suspicious PowerShell activity and identify persistence through the Startup folder, Registry keys, and scheduled tasks.
- [BTLO: Eradication](eradication.md) — A YARA-based threat-hunting investigation using yarGen, recursive scanning, and Joe Sandbox enrichment to locate hidden artifacts and identify Snake Keylogger.
- [BTLO: Phishy V1](phishy-v1.md) — A static analysis of a phishing site and exposed kit, tracing cloned-page resources, credential processing, the collection address, redirect behavior, and the variable mismatch that breaks the workflow.
- [BTLO: Basilisk 1](basilisk-1.md) — A static malware-analysis walkthrough using BinText, Exeinfo PE, PEiD, CFF Explorer, and PEview to examine strings, PE headers, entry points, imports, packing indicators, and timestamps.
