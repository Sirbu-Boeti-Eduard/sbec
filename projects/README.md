# Projects

Open-source projects and contributions.

## Projects

- [tlspect](tlspect.md) — A focused Go CLI for auditing TLS certificates, protocols, ciphers, and HTTP security headers, scoring a public endpoint 0-100 with a prioritised remediation list.
- [ArchiveGate](archivegate.md) — A signature-aware, policy-driven recursive ZIP preflight inspector in Go that never extracts archive contents to disk.
- [email-dumper](email-dumper.md) — Automated email dumping for penetration testing and CTFs, saving every IMAP or POP3 message as `.eml` files.
- [CVE-2026-48939 — iCagenda Unauthenticated File Upload to RCE](cve-2026-48939-icagenda-poc.md) — Built a functional PoC script for a critical Joomla iCagenda vulnerability after the original disclosure lacked a working exploit. Added CSRF token handling, active shell verification, and a self-contained bash-based exploitation tool.
